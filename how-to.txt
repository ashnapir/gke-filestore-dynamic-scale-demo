1. Cluster Creation: 
gcloud container clusters create my-vac-cluster --zone=us-central1-a --cluster-version=1.35.2-gke.1842000 --num-nodes=10 --addons=GcpFilestoreCsiDriver --no-enable-autoscaling

2. Attributes Class definition: kubectl apply -f vac-17k.yaml

3. Dynamically Provision a Filestore Instance using a PersistentVolumeClaim: kubectl apply -f dynamic-pvc.yaml

4. Create Deployment: kubectl apply -f base-deployment.yaml

5. Follow logs to validate Filestore deployment: kubectl get events -w | grep fio-dynamic-pvc

6. Show GKE Storage Configuration in UI

7. Install FIO on all the PODs: ./install_fio.sh

8. Run FIO on all the PODs: ./run_fio.sh

9. Present list of deployed PODs: ./list_fio_pods.sh

10 Show performance dashboard:
Reads IOPS are hitting instance limit
Read latency is high

11. Show Filestore instance configuration:
gcloud filestore instances list --filter="labels.kubernetes_io_created-for_pvc_name:fio-dynamic-pvc"
gcloud filestore instances describe ZZZZZ --zone=XXXX

12. Update Filestore performance limits: kubectl patch pvc fio-dynamic-pvc -n default -p '{"spec": {"volumeAttributesClassName": "filestore-17k-iops"}}'

13. Show updated Filestore instance config: gcloud filestore instances describe ZZZZZ --zone=XXXX

14. Show Performance Dashboard to present updated performance

15. Run the failure simulation script: ./failure_simulation.sh

16. Wait till completed and show PODs status: ./list_fio_pods.sh

17 Show Performance Dashboard to present performance behaviour
